Todot Programming Language | لغة تودوت

Todot is an experimental Arabic-friendly programming language designed to make programming more accessible to Arabic speakers.

تودوت هي لغة برمجة تجريبية تدعم كتابة الأوامر البرمجية باللغة العربية، وتهدف إلى تسهيل تعلم البرمجة للناطقين بالعربية.

- Project: Todot Programming Language
- Status: Experimental / قيد التطوير
- Platform: Android using Termux
- Repository: https://github.com/ghsanabwalwfa654-ctrl/Todot

Why Todot? | لماذا تودوت؟

Todot explores a simpler, more accessible way to write code using Arabic keywords.

تجرب تودوت أسلوبًا أبسط لكتابة البرامج باستخدام كلمات برمجية عربية، لتقريب البرمجة من المستخدم العربي.

Installation | التثبيت

Install Termux on Android, then run:

pkg update
pkg install python curl
curl -fsSL https://raw.githubusercontent.com/ghsanabwalwfa654-ctrl/Todot/main/install.sh | bash

Start programming:

todot hello.td

Hello World | أول برنامج

Create a file named "hello.td":

#p
اطبع "Hello from Todot!"
اطبع "هيا نبدأ البرمجة"

Run it:

todot hello.td

Expected output:

Hello from Todot!
هيا نبدأ البرمجة

Current Features | المميزات الحالية

The experimental version focuses on basic programming features, including:

- Arabic print statements using "اطبع".
- Basic variable assignments.
- Arithmetic expressions.
- Experimental translation to supported programming-language targets, depending on the installed compiler version.

تركز النسخة التجريبية على أساسيات البرمجة، مثل:

- الطباعة باستخدام "اطبع".
- إسناد القيم إلى المتغيرات.
- العمليات الحسابية.
- تجربة تحويل الشيفرة إلى لغات برمجة أخرى وفقًا لإصدار المترجم.

Note: Features may be limited and are subject to change as the project develops.

ملاحظة: بعض المميزات ما زالت محدودة، وقد تتغير مع تطور المشروع.
